# Screenshots

Drop your images here using these exact filenames — the main
[`README.md`](../README.md) already references them, so they'll render as soon
as the files exist.

| Filename | What to capture |
| :-- | :-- |
| `dashboard.png` | The Study Notes dashboard with a few captured topics visible (summary, key takeaways, a code block) |
| `chat-hub.png` | The Multi-AI Chat Hub tab, ideally mid-conversation with the engine pills visible |
| `popup.png` | The extension popup, showing detected AI engines and the Capture button |
| `docx-export.png` | An exported `.docx` opened in Word, showing the colour formatting |
| `flashcards.png` | Flashcard study mode |

**Tips**

- Capture at a normal window size (roughly 1440–1920px wide) so text stays readable.
- Light theme generally reads better on GitHub, which most people browse in light mode.
- PNG is preferred; keep each file under ~1 MB so the repo stays light.
